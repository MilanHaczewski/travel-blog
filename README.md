# Tulips & Arepas

Tulips & Arepas is a multilingual travel blog created by Milan and Juliana to share their adventures between Europe and Colombia. The project brings together personal travel stories, destination pages, photos, videos, comments, and an interactive map that highlights the places they have written about.

What makes the project special is that it is not just a blog, but a shared digital journal. It combines slow travel, interrail trips, city memories, island escapes, and everyday moments into one place, while keeping content easy to manage for both creators through a private dashboard with live preview and media uploads.

## Highlights

- Multilingual interface and content support in Dutch, English, and Spanish
- Interactive map with pinned destinations and continent filtering
- Public travel stories with photos, videos, tags, and comments
- Admin dashboard with live preview for new posts and destinations
- Invitation-based administrator access with master-admin controls
- Destination and tag management for organizing stories over time

## Built With

- Laravel
- Inertia.js
- React
- TypeScript
- Vite
- Tailwind CSS

## Project Vision

Tulips & Arepas was built as a warm and personal place to document a shared life of travel. From train journeys through Germany and the Czech Republic to memories in Medellin, Cartagena, and Isla Fuerte, the platform is meant to grow into a living archive of stories, routes, and moments worth keeping.
